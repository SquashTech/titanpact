Trigger Keywords

Of the 450 passive lines across innates, Evolution paths, Boons, Classes and gear, about 275 open with one of eight trigger clauses. Each is already a single reactive.hook in the data, so the keyword can be derived from the engine's own fields and can never drift from what the card does.

Two modifiers ride on any keyword instead of becoming keywords of their own: 1Once for "the first time … each fight" (11 lines), and a round count for "every third round". No subject means this hero; anyone else is named ("Partner", "Foes").

Questions this raises

  1. "Lands a hit" and "lands an attack" are the same data. Both read DamageDealt with the hero as source. The same goes for "finishing blow" and "knocks out a foe", "takes a hit" and "takes damage", and "foe" and "enemy". A keyword would fold these together, which is a cleanup on its own merits.
  2. Where does a new player learn the glyph? The tips are down to three, so a glyph can't be taught there. C keeps the word beside the glyph everywhere, so it teaches itself. D needs a long-press, which is a screen the player has to think to open.
  3. Should the effect half drop its subject too? B–D drop "it" and "this hero" ("Gains DEF ▲"), which only works if the rule is that no subject means this hero. That rule would show up in every line, so it needs to hold everywhere.
  4. Who writes the line? The trigger can be drawn from the hook, with the author writing only the effect half and a test checking the two match. The alternative is hand-editing 275 descriptions, which will drift again.
  5. The long tail stays prose. "When an enemy takes Burn damage", "When this hero's Defense rises" and others under 8 lines each are better spelled out than given a fifteenth glyph to learn.
