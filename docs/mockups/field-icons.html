Field Effect Icons

Each cell shows the icon in the field's dossier disc, then at the size it sits beside text, as on a move's Sets row. Today five fields use 32px pack icons that are all the same green arrows with a small accent. The other four have no icon and fall back to their type glyph, so a move's "Sets Downpour" draws the same picture as a Water move.
