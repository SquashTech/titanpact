First Light, three ways

Each shows the title on a new account's second visit: the first lesson won, the second next. Use the buttons to see other points along it.

  • The lessons still go unnamed: they're known by who you fight beside, the heroes' own sprites, which is a promise a name never made.
  • A lesson you haven't reached shows its heroes as silhouettes: you see that someone is coming, not who.
  • When First Light is won, each version still folds into the Pact's clasp as it does now; only the trail before that changes.
